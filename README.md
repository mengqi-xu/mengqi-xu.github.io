# mengqi-xu.github.io

Personal academic website of Mengqi Xu. Plain HTML/CSS with no build step.

- `index.html`: about, recent news, selected manuscripts, education, experience, service, contact
- `publications.html`: manuscripts, ongoing projects, software
- `talks.html`, `teaching.html`
- `assets/style.css`: all styles (light and dark modes follow the system setting)

The profile photo is `assets/photo.jpg` (a square crop looks best). If it is missing, an "MX" initials circle is shown instead.
